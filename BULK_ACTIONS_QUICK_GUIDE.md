# Quick Guide: Bulk Question Actions

## What's New? 🎉

You can now **select multiple questions** at once and **delete them in bulk**!

---

## How to Use

### ✅ Select Individual Questions

1. Go to **Questions tab** in Create/Edit Exam
2. Each question now has a **checkbox** on the left
3. Click checkbox to select/deselect individual questions

```
☐ 1. What is 2+2?        [X]
☐ 2. What is 3+3?        [X]
☑ 3. What is 4+4?        [X]  ← Selected
☐ 4. What is 5+5?        [X]
```

---

### ✅ Select All Questions

At the top of the question list, click:

```
┌────────────────────────────────────┐
│ ☐ Select All (20)                  │
└────────────────────────────────────┘
```

Click again to **deselect all**.

---

### ✅ Delete Selected Questions

After selecting questions, a **red delete button** appears:

```
┌──────────────────────────────────────────────┐
│ ☑ 5 of 20 selected    [Delete Selected (5)] │
└──────────────────────────────────────────────┘
```

Click it to **delete all selected questions at once**!

## Common Workflows

### 🗑️ Delete Specific Questions

```
1. Check questions 3, 7, and 12
2. Click "Delete Selected (3)"
3. ✅ Done! 3 questions removed
```

### 🗑️ Delete All Questions

```
1. Click "Select All"
2. Click "Delete Selected (20)"
3. ✅ Done! All questions cleared
```

### 🗑️ Keep Only Some Questions

```
1. Click "Select All" (all checked)
2. Uncheck questions you want to keep
3. Click "Delete Selected"
4. ✅ Done! Only unchecked questions remain
```

---

## Visual Cues

### When Questions Are Selected

- ✅ Checkbox shows checkmark
- 📊 Selection count updates
- 🔴 Delete button appears
- 🎯 Button shows count: "Delete Selected (5)"

### Hover Effect

Questions have a **hover effect** when you mouse over them:
- Border color changes
- Makes it easier to see which question you're about to select

---

## Tips

💡 **Tip 1:** You can still delete individual questions using the **[X]** button on the right

💡 **Tip 2:** The selection is cleared after bulk deletion

💡 **Tip 3:** If you delete a question individually while it's selected, it's automatically removed from selection

💡 **Tip 4:** You can't delete with zero selection - you'll see an error message

---

## Keyboard Shortcuts

- **Tab**: Navigate between checkboxes
- **Space**: Toggle checkbox selection
- **Enter**: Activate focused button

## Example Scenarios

### Scenario 1: Removing Duplicates

```
You have 30 questions, but questions 10-15 are duplicates.

1. Select checkboxes for questions 10-15
2. Click "Delete Selected (6)"
3. Done! 24 unique questions remain
```

### Scenario 2: Starting Fresh

```
You want to replace all questions with new ones.

1. Click "Select All (30)"
2. Click "Delete Selected (30)"
3. Upload new CSV with fresh questions
4. Done! Complete replacement
```

### Scenario 3: Selective Cleanup

```
You want to remove all "Easy" difficulty questions.

1. Scroll through and check all Easy questions
2. Might be questions 1, 3, 8, 12, 15, 20
3. Click "Delete Selected (6)"
4. Done! Only Medium and Hard remain
```
